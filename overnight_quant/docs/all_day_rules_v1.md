# 全天观察独立规则草案 v1（待验证，非生产）

不继承旧综合评分、权重、阈值或资格。演示状态只计算合成样本；参数为研究假设，不是最优值或概率。所有输入须同一身份、交易日、明确批次、单位及已知事件/可用时点，缺失、未来、过期、重复冲突或不同批不兼容时资料不足。仅两次报价只可比较两点，不能证明突破、回踩或可成交。

| 层次 | 输入及窗口/公式 | 演示阈值与输出 | 缺失处理 |
| --- | --- | --- | --- |
| 市场 | 明确基准当日涨跌与同一观察点全市场身份去重后上涨数/有效数，记录有效总数及分母 | 待验证：基准>0且上涨占比≥60%为偏强；基准<0且上涨占比<40%为偏弱；其余为分化，0值明确不计上涨。原型没有完整市场样本，固定“资料不足” | 基准或覆盖未知、分母0/时点不同，不给强弱/分化标签；五股不可代替全市场 |
| 题材 | 同一时点完整概念成员及涨跌，扩散=上涨有效成员/全部有效成员；五日相对=题材五交易日收益减同窗口同口径基准收益（百分点）；再看同批当日题材涨跌 | 相对≥1、扩散≥60%、当日≥0为走强；相对≤-1或扩散<40%为走弱；其余分化。先判断走弱，阈值和5日窗口待验证 | 任何必要输入缺失/非有限、分母0、覆盖/身份/时间未证明或扩散不在[0,1]为资料不足；无自动补零 |
| 趋势核心 | 概念归属、同窗口收益与趋势结构、相对题材/基准及可用时间 | 待验证建议：至少5个已完成交易日、相对基准为正且最近价高于对应5日均价，展示数值和归属依据，不设名次为龙头 | 缺日/口径/历史成分为资料不足；展示中的角色为人工合成假设 |
| 活跃核心 | 同批成交额、换手、量额单位、样本内排名及时间 | 待验证建议：在完整概念成员中按当日成交额降序列前3，再展示换手；不单用涨幅第一 | 量额单位、覆盖或时点未知则不可判；不虚构缺失额 |
| 连板核心 | 独立交易日历、当日及此前连续涨停/开板事件、身份和可交易状态 | 待验证建议：连续至少2个交易日均有完整涨停事件证据；不将单次触价当封板 | 涨停/开板连续证据或停牌未知则资料不足；原型仅人工假设 |
| 突破观察 | 用户提供上沿与失效价、实际未复权价、有效事件与可用时间；条件值均为正且失效价<上沿 | 单点≥上沿只能显示“满足观察条件”；需另行证明持续轨迹及可交易性才能称突破确认。≤失效价显示条件失效 | 缺价/身份/口径/时间/期限则资料不足；不默认实际买卖价 |
| 回踩观察 | 已证明的此前突破、触及回踩区间及其后重新站稳的有序连续轨迹 | 参数待验证；本原型未实现确认，固定资料不足 | 两个点无法证明中间路径，不从涨跌推断回踩 |
| 持仓与退出 | 用户自述买入日期、数量、是否可卖、价格条件、风险/公告 | 分“未提供/今日买入/可卖持仓”显示人工核验提醒；失效是取消观察，不生成卖出指令 | 未核验、未知、不可卖均不能自动通过；不推导交易许可 |

原型所用示例方向、股名、价位、成分、角色和日期都是虚构演示，不写入真实设置、正式records或交易输出。用户备注仅会话内，不自动访问链接；真实历史跟踪与人工备注仍由原工作区提供。qualification=0/3、data_ready=false、hard_gate_authorized=false，正式records/candidates/tickets/orders均空。

# 工作包3：条件变化记录与人工风险备注

合同 `observation_tracking_v1`。沿用现有Dashboard、ObservationStore与绝对价格条件，不改变来源、策略、生产就绪、价格阈值或风险门禁。

## 三步操作

1. 在历史/离线观察选择材料空间，加载明确的设置版本，加入跟踪；明确选择前后两份快照与两侧规则版本。
2. 查看历史比较后点击“保存所选比较记录”。同一证券、两批次和规则版本组合只保存一次；同快照、倒序、来源/口径不兼容及未确认批次不能保存为有效变化。资料不足显示“数据不足”，不生成伪造事件。
3. 填写检查事项、结论、依据文本/链接，可选择待复核或填写带时区的复核到期时间，点击“保存人工备注新版本”。选择旧备注版本可追加修改，原件不覆盖。链接仅保存文本，不自动访问。

## 解释与状态

- 沿用已有compare/evaluate，分别展示不满足→满足、满足→不满足、保持不变、数据不足、规则已修改。规则改变时不将状态差异归因于行情；两点不证明连续路径、突破或成交机会。
- 保存的是用户明确比较的历史记录，不是当前提醒。现有主动刷新页面仍按原生事件重算60秒年龄；刷新失败不借旧价判断，历史比较不重置报价年龄。
- 比较记录保存原始批次/证据SHA、规则版本、前后状态/价格/原生事件及用户保存时刻。没有按mtime静默选择最新文件；列表表示最近一次明确保存的比较，非自动监控。
- 人工备注始终为“用户记录，系统未核实”。未记录、已记录、待复核、已到期仅为记录管理状态，不对应CLEAR或审核通过。不同检查事项不会因新增一条普通备注而掩盖仍到期的事项；被明确修改的旧版本保留历史，不再主导当前汇总。
- 到期由用户填写，按当前时间动态判断，不替用户设定新闻/公告期限。实际记录时间由程序保存时生成，不允许用户回填。风险/可交易性NOT_ASSESSED，资格0/3、data_ready=false、hard_gate_authorized=false，正式records/candidates/tickets/orders为空。

## 存储与默认关闭

记录在对应historical或synthetic_test_only空间的observation_tracking_v1下，变化与备注独立、不可覆盖、内容hash校验。并发同事件只允许一个保存者；未完成保存标记不自动删除或绕过。旧设置、快照、用户持仓、正式记录均不改写。无新增依赖、数据请求、调度、提醒或交易接口。

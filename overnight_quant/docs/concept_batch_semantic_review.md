# 概念与成分：字段依据及展示边界

适用于现有降序概念结构合同的只读展示。采集、确认、独立重放、来源资格及上游用途 `UNKNOWN` 均未改变。页面只读取配置的本地交付索引，仍要求原始报告和最终确认的外部 SHA 锚点；不从文件修改时间推断最新批次。

| 字段 | 上游公开页面或代码 | 维护方实现 | 项目结论及页面行为 |
| --- | --- | --- | --- |
| 概念列表、BK、名称 | [东财板块页](https://quote.eastmoney.com/center/boardlist.html#concept_board)的[静态代码](https://quote.eastmoney.com/center/static/build/index.js)将 `concept_board` 绑定 `m:90+t:3+f:!50`，与地域和行业分开。[东财板块详情](https://quote.eastmoney.com/bk/90.BK0939.html)展示 BK0939 与辅助生殖。 | [AKShare 概念列表](https://github.com/akfamily/akshare/blob/62a56b2159add40f41b2c19129be3ac2af297d09/akshare/stock/board/stock_board_concept_em.py#L25-L76)使用同一概念筛选，映射 `f12` 为代码、`f14` 为名称。 | 只说明来源分类和标签。页数上限内的有限集合不是全市场，按代码选中的 BK 不是热门题材。 |
| 成分归属 | 同一东财静态代码的板块明细路由选用 `bkchild`，从板块标识取 BK 后使用 `b:{BK}+f:!50`。 | [AKShare 板块成分](https://github.com/akfamily/akshare/blob/62a56b2159add40f41b2c19129be3ac2af297d09/akshare/stock/board/stock_board_concept_em.py#L387-L437)使用相同 BK 筛选。 | 重放对照请求和原件，核对每页确实绑定所选 BK。因此可称“来源返回的概念及成分”，不是客观、唯一或可回溯的历史归属定义。旧合同未用本结论自动升级。 |
| `f3` 涨跌 | 东财静态代码把 `f3` 用于涨跌幅百分数显示，渲染同时使用精度字段；未在该路径说明计算基准，也未明确本批 `fltt=2` 原值缩放。 | 上述列表及成分映射为涨跌幅；成分另有昨收字段，但映射本身不是比较公式。 | **不计算真实分布**：封存未请求昨收，不能独立校对比较基准。结构可读数不等于指标有效。仅在另有基准、单位依据且成分覆盖完整时，以有效成分的正、负、零计数；上涨占比为上涨数除以有效数，无效不当平盘。 |
| `f6` 成交额 | 东财静态代码将 `f6` 渲染为成交额；[东财旗下公开介绍](https://fund.eastmoney.com/a/202508193488269136.html)解释一般盘口成交额是当日累计，但不定义本成分接口的原值单位和具体统计期间。 | 上述成分实现将 `f6` 映射为成交额，未给出本接口单位和统计期间。 | **不排名**：有数值不代表可比。仅在单位、统计期间及完整成分均有依据，且成交额全部有效时，按成交额降序取至多三只、同值按证券身份；称批次成交活跃代表股，不称龙头。 |
| `f124` 时间 | 东财通用显示代码把 `f124` 接到“交易时间”并按 Unix 秒格式化；未证明当前成分表中其事件含义、同步性、发布或最终性。 | 列表实现请求该字段但未纳入概念列表输出；上述成分实现未请求该字段。 | 源数据时点未确认。即使值可解释为同日整数秒，也不能将其当作本批统一行情时点，更不能用本地采集时间替代。 |

核验仅使用公开 HTML、静态 JavaScript、维护方源码及本地已封存原件，未运行上游页面代码或发出行情请求。通用页面标签与客户端映射不是接口长期承诺。测试数据的计算不构成真实字段证明。未开启实时、最终收盘、盘中走势、题材热度、历史成员、风险确认或交易功能。

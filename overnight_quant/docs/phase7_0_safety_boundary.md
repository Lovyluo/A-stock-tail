# v0.4 安全边界

## 固定边界

`close_confirmation_v1` 只提供：

- 时点快照；
- 特征、门禁和影子评分；
- 历史事件回测；
- 本地纯模拟资金与持仓计算；
- 观察报告、风险提示和审计字段。

当前版本不会：

- 连接外部交易端；
- 提交真实委托；
- 操作证券客户端或交易页面；
- 绕过 session gate、risk gate 或数据质量门禁；
- 将 `DATA_FALLBACK_DEMO` 转换为候选、模拟意图或票据；
- 用缺失分钟数据时的日线收盘价替代时点数据。

## 正式数据规则

`live`、`shadow`、`paper` 和 `replay` 输出必须满足：

- `demo_field_count = 0`；
- 数据失败时返回空候选和明确错误；
- 新闻缺失发布时间时不评分；
- 14:50 后到达的数据不参与当日决策；
- 所有输入可追溯到来源、版本、请求哈希和原始数据哈希。

## 研发状态

新策略在完成历史验收和影子验收前：

- `formal_signal_enabled = false`；
- `ticket_enabled = false`；
- Dashboard 显示“策略研发/影子模拟中”；
- 旧策略仅作为冻结复现基线。

## 使用者责任

任何评分、回测、影子候选或模拟持仓都不构成投资建议，也不保证未来表现。
数据可能延迟、缺失、修订或错误，使用者对所有实际投资判断和损失自行负责。

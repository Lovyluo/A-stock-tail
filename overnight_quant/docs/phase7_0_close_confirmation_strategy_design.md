# v0.4 行业共振尾盘确认策略设计

## 1. 状态与目标

`close_confirmation_v1` 是研发中的尾盘确认策略。当前生命周期为
`research_shadow`，只产生影子观察结果，不产生正式信号、人工票据或任何外部执行动作。

原 `yang_yongxing_overnight_v1` 保留为 `legacy_frozen_baseline`，用于回放和回归，
不再调参，也不再作为正式入口。

## 2. 决策与采集时间

- 14:40-14:50：采集市场、行业、个股分钟行情、盘口、资金代理和消息。
- 14:50：冻结不可变决策快照。
- 14:50 之后到达的数据不得改变当日 14:50 决策。
- 完整读取 14:50 分钟线时，最早模拟成交时间为 14:51。
- 14:56 撤销未成交数量，不使用收盘价补单。

所有输入必须满足 `available_at <= decision_time`。新闻还必须有明确
`published_at`，且发布时间不得晚于 14:50。无发布时间的新闻、盘后公告和晚到数据
只进入后续审计，不参与当日评分。

## 3. 五个硬门禁

1. 市场门禁：主要指数与市场广度不能处于明显弱势。
2. 行业门禁：行业相对强度和上涨广度必须形成共振。
3. 流动性门禁：成交额、换手率、停牌和涨跌停可交易状态合格。
4. 消息风险门禁：决策前可见的明确负面公告不得超过阈值。
5. 数据质量门禁：必须有完整 14:50 分钟数据，正式模式不得含演示字段。

任一门禁失败，结果只能是拒绝观察，评分不能绕过门禁。

## 4. 初始评分

| 维度 | 权重 |
|---|---:|
| 市场确认 | 15 |
| 行业确认 | 20 |
| 个股相对强度 | 15 |
| 量价确认 | 25 |
| 催化质量 | 10 |
| 筹码结构代理 | 15 |

评分检查以下信息：

- 市场和行业相对强度、行业上涨广度；
- 个股相对行业强度；
- VWAP 位置与斜率；
- 尾盘回踩承接；
- 标准化异常量；
- 极端订单失衡；
- 筹码成本代理、上方压力和下方支撑；
- 有明确来源与发布时间的催化和负面公告。

主力资金与筹码峰均为代理指标，不代表真实主力行为或真实持仓成本。

## 5. 事件成交与持有

- 买入模拟只读取 14:51-14:55 的分钟事件。
- 支持部分成交、停牌、涨跌停阻塞、日期相关涨跌幅限制、滑点、冲击成本和 100 股整手。
- D1 只允许风险退出，遵守 T+1。
- D2-D5 在市场、行业、催化或结构失效时退出。
- D5 无条件时间退出。
- 连续跌停无法退出时延长持有并单独累计 `blocked_days`。

## 6. 纯模拟资金约束

默认模拟资金 100000 元：

- 单票上限 10%；
- 总暴露上限 30%；
- 最多 3 只；
- 单票风险预算 0.5%；
- 所有数量向下取整为 100 股。

模拟账户仅在本地计算，不连接任何外部交易端。

## 7. 历史研究协议

- 按日期滚动：36 个月训练、6 个月验证、6 个月测试；
- purge 和 embargo 各 5 个交易日；
- 最近 12 个月封存，只允许打开一次；
- 股票池必须保留退市股和历史 ST、停牌状态，禁止幸存者偏差；
- 至少 5 年、8 个样本外窗口、300 笔可成交交易；
- OOS Sharpe >= 0.8、Profit Factor >= 1.20、DSR >= 95%、PBO <= 20%；
- 逐日盯市最大回撤 <= 15%；
- 每边额外增加 10bp 后净收益仍为正。

封存测试失败后不得通过修改封存集阈值补救。

## 8. 影子验收

只有历史门槛全部通过后，才开始不少于 60 个交易日且不少于 50 笔成交的影子模拟。
60 日内成交不足 50 笔时延长到 90 日，不降低阈值。

当前尚未完成历史与影子验收，因此 Dashboard 必须显示“策略研发/影子模拟中”。

## 9. 风险边界

本策略不构成投资建议，不保证收益。所有结果仅用于研究观察和风险复核。
详细边界见 `phase7_0_safety_boundary.md`。

## 10. 输入完整性门禁

冻结快照与策略入口共同调用统一 readiness validator。市场、行业、完整 quote、
14:50 分钟线、60 日量价历史、资金流代理和新闻来源状态缺一时，
`execution_ok=true` 但 `data_ready=false`，状态为
`POINT_IN_TIME_DATA_INCOMPLETE`。

缺失数据不使用中性默认分：

- 市场或行业字段缺失时对应分量 unavailable，相关硬门禁失败；
- 新闻源成功但零条催化时催化分为 0；
- 新闻源失败属于数据不完整，不等同于零新闻；
- 日线或资金流不足时筹码代理分为 unavailable；
- demo 字段触发 `FORMAL_DATA_REJECTED`，同时强制 `data_ready=false`。

只有完整输入至少完成一只股票的实际评分后，状态才允许为
`SHADOW_SIMULATION_READY` 或 `NO_SHADOW_CONFIRMATION`。
